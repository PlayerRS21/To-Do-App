# ✅ To-Do App

A simple and efficient Python-based to-do list application.

## 📋 Overview

To-Do-App is a productivity tool that helps you manage your tasks and stay organized.

## 🚀 Getting Started

### Prerequisites
- Python 3.6 or higher
- tkinter (usually included with Python)

### Installation

```bash
git clone https://github.com/PlayerRS21/To-Do-App.git
cd To-Do-App
pip install -r requirements.txt
```

### Usage

```bash
python main.py
```

## ✨ Features

- ✏️ Add new tasks
- ✅ Mark tasks as complete
- 🗑️ Delete tasks
- 💾 Save tasks to file
- 📂 Task categories
- 📅 Due date tracking
- 🎨 User-friendly interface
- 🔄 Task sorting

## 📖 How to Use

1. **Add Task** - Enter task name and click "Add"
2. **Mark Complete** - Check the box when done
3. **Delete Task** - Remove completed or unwanted tasks
4. **Save** - Tasks auto-save
5. **Organize** - Use categories and due dates
